# Design documents

This folder holds current, first-party Comet-MCP architecture material written for this project.

- `00-multi-provider-backbone-executive-synthesis.md` is a concise executive summary.
- `01-turn-01-critique-and-outline.md` records the initial critique and recommended direction.
- `02-turn-02-complete-synthesis-phases-and-task-list.md` preserves the complete Turn-02 synthesis, detailed task list, phase gates, and test matrix.
- `../build-plan.md` is the concise, execution-oriented plan.

The files in `../reference/` are external/background inputs. When they disagree, the current design documents, accepted architecture decisions, and build plan take precedence.
